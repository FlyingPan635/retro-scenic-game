# cloud&hill

**v1.03 · 正式版 · 2026-10-01**

一个可自由探索的复古低模 3D 小世界。沿着草坡和小路漫游，经过马戏团、风车与小溪，看飞鸟盘旋、猫和老鼠打盹，听随距离自然变化的音乐与环境声。

## 开始游玩

Windows 上安装 Python 3 后，双击 `Play.cmd`，浏览器会自动打开游戏。游玩期间保持命令窗口开启，关闭窗口或按 Ctrl+C 结束服务器。

也可在本目录运行：

```powershell
python serve.py
```

本地地址为 `http://127.0.0.1:8000`。端口被占用时，先关闭此前的服务器再启动。需要支持 WebGL 和 Web Audio 的现代浏览器；也可用其他静态文件服务器打开本目录。请通过服务器访问，不要直接双击 `index.html`。

Three.js 随项目附带，配乐和音效由浏览器实时合成，游玩无需联网、下载素材或安装前端依赖。

## 操作

| 操作 | 键盘 / 鼠标 |
| --- | --- |
| 前进、后退 | W / S 或 ↑ / ↓ |
| 角色转向 | A / D 或 ← / → |
| 奔跑 | Shift |
| 跳跃 | 空格 |
| 环顾 | 鼠标左键拖动 |
| 视角缩放 | 鼠标滚轮 |

角色转向与镜头方向独立，镜头跟随角色移动和跳跃。窄屏触控设备使用左侧摇杆移动和转向，右侧拖动画面环顾，右下按钮跳跃。

首次按键或触屏操作后启用声音。浅水会减慢脚步、减轻跳跃重力，并沿河道推着角色移动。

## 正式版内容

- 可探索的草坡、道路、树林、马戏团、风车与动态河流。
- 自由镜头、奔跑、跳跃与浅水交互，支持键鼠及窄屏触控操作。
- 分段机翼飞鸟，包含振翅、滑翔、转弯与尾羽动作；猫和老鼠保留睡觉动画。
- 原创循环配乐《cloud&hill 小夜曲》，配合马戏团的旋转木马乐句与风车的笛声乐句。景物音乐随距离平缓淡入淡出，保持接近主题曲的响度。
- 风声、同步风车叶片声、随飞鸟位置变化的鸟鸣、程序合成溪流，以及脚步、入水、跳跃和落地音效。花丛与睡觉动物不发声。

本次定版清理旧音效试听、运行日志、Python 缓存及空素材目录；保留游戏模块、本地启动器、第三方许可和音频回归检查。

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html`、`style.css`、`favicon.*` | 页面、触控界面与图标 |
| `main.js` | 游戏循环、输入、镜头及场景动画 |
| `map.js` | 地图配置与出生点 |
| `world.js` | 地形、景物、河流与世界构建 |
| `avatar.js`、`movement.js` | 玩家造型与移动计算 |
| `bird-flight.js`、`sleepers.js` | 飞鸟轨迹与动物动画 |
| `audio.js`、`stream-audio.js` | 配乐、环境声与溪流合成 |
| `vendor/` | 离线 Three.js 与 MIT 许可证 |
| `Play.cmd`、`serve.py` | 本地启动及防缓存服务器 |
| `tests/audio-check.cjs` | 遗留开发用音频与入水检查，不参与自动发布 |
| `VERSION` | 正式版本号 |

## 修改地图

开发约定见 [AGENTS.md](./AGENTS.md)：每轮修改完成后版本号增加 `0.01`，固定保留两位小数，并同步更新 `VERSION` 与本说明中的版本号和日期。本次版本为 `1.03`，下一次修改为 `1.04`。

编辑 `map.js`，刷新页面即可查看结果。坐标范围约为 `-75` 到 `75`。

- `terrain.hills` / `terrain.waves`：山丘与草坡起伏。
- `river.points` / `river.width`：河道与水面宽度；河床、河岸和水纹自动生成，树木避开水面。
- `paths`：由 `[x, z]` 点组成的贴地道路。
- `objects` / `groves`：景物与远景树林。
- `birds` / `sleepers`：飞鸟与打盹动物，动物支持 `mouse` 和 `cat`。
- `spawn`：出生位置、角色朝向与初始镜头方向 `cameraYaw`。
